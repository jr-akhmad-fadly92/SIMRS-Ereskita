SIMRS Ereskita - ( Sistem Informasi Manajemen Rumah Sakit )

Ringkasan

Sistem informasi berbasis web untuk mendukung alur operasional klinik, mulai dari
pendaftaran pasien hingga proses pembayaran. Dikembangkan untuk digunakan oleh
staf front office dan kasir klinik dalam mengelola antrian dan transaksi harian.

Fitur

- Modul pendaftaran pasien (data dummy untuk ilustrasi)
- Manajemen antrian pemeriksaan
- Modul pembayaran & cetak kuitansi
- Dashboard ringkasan transaksi harian

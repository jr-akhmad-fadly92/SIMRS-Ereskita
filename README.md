SIMRS Ereskita - ( Sistem Informasi Manajemen Rumah Sakit )

- Ringkasan

Sistem informasi berbasis web untuk mendukung alur operasional klinik, mulai dari pendaftaran pasien hingga proses pembayaran. Dikembangkan untuk digunakan oleh staf front office dan kasir klinik dalam mengelola antrian dan transaksi harian.

- Fitur

1. Modul pendaftaran pasien (data dummy untuk ilustrasi)
2. Manajemen antrian pemeriksaan
3. Modul pembayaran & cetak kuitansi
4. Dashboard ringkasan transaksi harian


Tech Stack
- Backend: PHP (Laravel) 5.5
- Frontend: Bootstrap 3.0
- Database: MySQL
